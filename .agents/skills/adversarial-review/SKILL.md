---
name: adversarial-review
description: Review a proposed code change for correctness, regressions, missing tests, and security issues. Use when a closeout policy names this skill.
---

Review the candidate revision against the supplied base revision.

Use references/rubric.md for the review criteria.

Report findings with severity, location, explanation, and supporting evidence. Do not modify the implementation during this review.

You are not the acceptance decision. The Closeout runner compares your findings with the policy.
